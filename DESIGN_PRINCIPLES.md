# Design Principles

1.

Architecture before features.

2.

Trust before autonomy.

3.

Local before cloud.

4.

Desktop before web.

5.

One companion.

Never multiple identities.

6.

Memory and Context remain separate.

7.

Planning and execution remain separate.

8.

Everything is modular.

9.

Prefer explicit behavior.

10.

Documentation is code.

11.

Every subsystem owns one responsibility.

12.

Explainability is a feature.

13.

Event-driven communication.

14.

Plugins extend MAVIS.

Skills extend the user.

15.

Every feature should reduce cognitive load.

16.

Performance follows architecture.

17.

Prefer Python.

Use Rust where justified.

18.

The user always owns their data.

19.

Privacy is default.

20.

Maintainability over cleverness.
